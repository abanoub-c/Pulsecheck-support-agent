# Asset sources

- **IBM Plex:** IBM’s official Plex page describes the type family as global and versatile. The app self-hosts IBM Plex Sans and IBM Plex Mono from the corresponding font packages to keep typography consistent and avoid a third-party runtime dependency. Source: https://www.ibm.com/plex/ . Google Fonts family pages: https://fonts.google.com/specimen/IBM+Plex+Sans and https://fonts.google.com/specimen/IBM+Plex+Mono .
- **Lucide React:** The official React guide documents standalone SVG React components, size/color/stroke customization, tree-shaking, and TypeScript support. The app imports only icons used in the UI from `lucide-react`. Source: https://lucide.dev/guide/react/ .

No stock illustration or decorative image assets are used; this is a data- and interaction-led internal support dashboard.
- **Pulsecheck mark**: custom SVG favicon at `public/pulsecheck-mark.svg`, drawn for this demo with the Terracotta pulse motif; no stock or third-party illustration is used.
